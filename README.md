# nutritionCalculator
> 栄養素計算

## outline
<p>
This app displays the nutritional content of each menu item.
</p>
<p>
栄養素をメニューごとに表示します。
</p>

## 参考にした背景
<p>下記によると、「30歳以上の女性395名の7割以上が栄養バランスを気にしている」「年代が高くなるほどその傾向は高まる」が、「2割以上が忙しくてできない」とのこと。</p>
<ul>
<li>
<a href="https://www.fnn.jp/articles/-/705631" target="_blank">30代以上の女性「栄養バランス派」と「食べたいものを食べる派」多数派はどちら？【食の安全性への意識・全国調査】</a>
</li>
<li>
<a href="https://www.sixthsenselab.jp/puravida/articles/research_food_safety/" target="_blank">【食の安全性への意識調査】３人に２人は国産志向が高いが、オーガニックへの関心は半数以下。</a>

</ul>

## 一番大事に考えること
<p>栄養バランスの取れた食生活を、楽しく続けられる人が増えること</p>

## phase1
<p>栄養バランスの取れた食生活を、楽しく続けることができる仕組みの基礎づくり</p>

## 楽しく続けるためには、
<ul>
<li>簡単にできる</li>
<li>メリットがあると実感できる</li>
<li>自己満足ができる</li>
<li>自己表現ができる</li>
<li>貢献していると感じることができる</li>
<li>承認されていると感じることができる</li>
<li>学びがあると感じることができる</li>
</ul>

### 「簡単にできる」仕組み
<ul>
<li>操作しやすいインターフェース</li>
<li>写真や動画で分かりやすい</li>
<li>気軽に始められる（必須項目や個人情報の取得が最低限等）</li>
<li>必要な食材が分かりやすい</li>
<li>外食時（イートイン・デリバリー・テイクアウト）も、お店のメニューの栄養バランスを確認でき、献立に追加できる</li>
<li>他の人が作った献立をセットすることができる※</li>
</ul>

### 「メリットがあると実感できる」仕組み
<ul>
<li>栄養バランスのとれた食事を作るためのサポートを受けることができる※</li>
<li>記録が確認できて食生活を改善できる※</li>
<li>ポイントを稼いで、使うことができる</li>
<li>運営から認定されたら、レシピを売ることができたり、仕事の依頼を受け付けることができる</li>
<li>時短料理、作り置き、節約をサポート※</li>
</ul>

### 「自己満足ができる」仕組み
<ul>
<li>過去の記録が確認できて自分で自分を褒めてあげることができる※</li>
</ul>

### 「自己表現ができる」仕組み
<ul>
<li>レシピを作って登録、シェアできる</li>
<li>自分が作ったレシピや献立をSNS等でシェアできる（他との差別化は、栄養素の詳細が書けるところ）</li>
</ul>

### 「貢献していると感じることができる」仕組み
<ul>
<li>レシピや献立を投稿して使ってもらうことができる（ポイントをもらえる）</li>
<li>家族や恋人、友人、その他のために、好みに合わせてオリジナルの献立を作ってあげることができる※</li>
</ul>

### 「承認されていると感じることができる」仕組み
<ul>
<li>いいねをもらう</li>
<li>レシピや献立を使ってもらう、保存してもらう</li>
<li>レビューでフィードバックをもらう</li>
<li>SNS等で共有される</li>
<li>自分のレシピを買ってもらえる</li>
<li>運営から認定される（継続率、レシピ投稿数、レシピ使用率、等）</li>
</ul>

### 「自分にとって学びがあると感じることができる」仕組み
<ul>
<li>栄養素に関して知ることができる</li>
<li>専門家や料理上手な人に質問ができる※</li>
<li>続けることで自然とおおまかな栄養バランスが分かるようになる（成長を感じることができるようなクイズ等：ポイントをもらえる）</li>
</ul>

<p>※は有料有り</p>
